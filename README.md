# AFTERIMAGE — 부찌만의 페르소나 아카이브

## 내용 고치는 법 (Pages CMS)

1. https://app.pagescms.org 에 GitHub로 로그인
2. `planetarium` 저장소 선택 → 왼쪽 **🌙 페르소나 관리**
3. 페르소나 추가·수정, 사진 올리기 → 오른쪽 위 **Save**
4. 1~2분 뒤 사이트 새로고침하면 반영돼요.

- 목록 순서 = 전시 순서예요. 6명이 넘으면 조각 묶음이 아래로 자동으로 늘어나요.
- 대표 이미지가 없으면 고른 장식(달·꽃·별 등)이 대신 나와요.

## 폴더

```
index.html            사이트
data/personas.json    모든 글 (편집기가 고쳐요)
images/personas/      올린 사진 (편집기가 채워요)
images/art/           사이트 장식 이미지
.pages.yml            편집기 설정
```
